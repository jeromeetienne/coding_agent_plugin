# Agent instructions

This repository holds the skills for coding agents. Read [CONTEXT.md](CONTEXT.md) for the purpose and the rules of the repository.

## Docs folder

Every file and every folder in the folder `docs` follows the skill [docs_folder_system](skills/docs_folder_system/SKILL.md). Read the skill before you add, change, rename, move, or delete a file or a folder in the folder `docs`.
The skill names no detail of this repository: it reads the values of this repository in the section "Docs folder system values" below.

### Docs folder system values

- Documentation folder: `docs`
- Files with no metadata header: none
