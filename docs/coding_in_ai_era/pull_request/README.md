This folder records the discussion about pull request review in the AI era. A pull request proposes a repository change; review helps the repository owner decide whether to accept the change and take responsibility for the change.

Start with [Discussion notes](discussion_notes.md). The notes distinguish the problem raised by Jérôme Étienne, proposed approaches, and questions still open for discussion. The proposals are not an adopted repository workflow.

Read [Requirements](requirements.md) for the current list of review requirements and the details still to be defined.
