# Coding in AI era

- Created: 14 November 2026
- Last updated: 14 November 2026
- Status: Maintained overview for people
- Related framing: [Agent instructions](../../AGENTS.md)

This folder captures Jérôme Étienne's approach to organizing coding in the AI era. AI produces code dramatically faster, which raises a broader question: how do humans remain in control of the software being built?

Pull request review is one part of that question. The collection also provides a place to develop other parts of the approach as the discussion continues.

Start with [Discussion notes](discussion_notes.md) for the overall purpose and the relationship between the existing skills. Read [Pull request review](pull_request/README.md) for the review discussion and requirements.
